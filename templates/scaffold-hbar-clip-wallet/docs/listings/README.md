# Listing drafts

`pnpm wallet:identity` writes listing-submission drafts here for your wallet's identity: EIP-6963, WalletConnect
Explorer, and (for the families clip.config.ts turns on) TON Connect, NEAR, Stellar Wallets Kit, Tezos Beacon and
Algorand use-wallet. Regenerate them with `pnpm wallet:listings`. Nothing is ever submitted for you.
