# Translation QA, October 2026

A second pass over every shipped translation: the extension UI (`packages/ui/src/i18n`), the mobile app
(`apps/mobile/src/i18n`) and OS notifications (`packages/social/src/notifications/locales`), for de, fr, es, pt-BR,
it, tr, ja, ko, zh-Hans, ar and hi. No native speakers took part, so the pass was conservative. It fixed clear
errors and lists everything that needs a fluent reader under "Needs a native speaker".

Checklist for every language:
1. Glossary adherence across UI, mobile and notifications.
2. Placeholders, plurals and ICU messages that read correctly for every plausible value.
3. Safety-critical strings keep their full strength.
4. Brand, product, device and network names stay untranslated.
5. Bidi isolation (Arabic).
6. Hindi completeness.
7. Truncation on tabs and buttons.

## New checks (run by `pnpm test`)

| Check | Where |

Plural categories must exist in the language. Arabic must have `few` and `many`. `=n` and select keys that English relies on must be kept. The helpers are exported from `@clip-wallet/i18n/qa`, a test-only entry point. App bundles never import it.

## Cross-language changes

- **Arabic bidi isolation.** All 260 Arabic messages that interpolate a value now wrap it in `⁨…⁩`, written as escapes in the source:
  - A handle keeps its `@` inside the isolate: `⁨@{handle}⁩`.
  - A sign or percent next to a value stays inside too.
  - Exception: `m.trade.share.android` keeps `{link}` bare so messaging apps can still linkify the URL. The test allowlists it.
  - Notifications are plain OS text with no `<bdi>` or CSS available, so the isolates are the only protection there.
- **Digits in messages.** `#` and `{n, number}` now use the same Latin digits as amounts in Arabic (`numberLocale`). Before this change, a device whose ICU defaults `ar` to Arabic-Indic digits could show "٣ أيام" next to "3 USDC".
- **Tab bars.**
  - Extension: a long one-word tab label (de "Einstellungen") can now hyphenate onto a second line instead of overflowing into the next tab (`.clip-tabbar__item span`, `hyphens: auto` with `<html lang>`).
  - Mobile: tab labels are limited to one line and shrink to at most 80 % (`adjustsFontSizeToFit`, in `apps/mobile/src/ui/kit.tsx`).
- **Decimal examples.** Hints like "Enter an amount like 25 or 0.5" now use the decimal mark the app displays: es and tr changed "0.5" to "0,5", matching de, fr, pt-BR and it. Hedera ids such as `0.0.1234` are unchanged.
- **Gender of the account label** (pt-BR, de, it). Every non-English locale gets the translated word from `approval.connect.account` in `approval.connect.lede`, never the English account label, so agreement is fixed per language. Results:
  - "sua conta", "dein Konto" and "il tuo account" were already correct.
  - ko now uses the fixed particle "{account}을", because the value is always "계정".
- **Relative-time phrasing.** `{when}` comes from `Intl.RelativeTimeFormat` with `numeric: "auto"`, so it can be "now", "5 minutes ago" or "yesterday". Phrasings that broke for "now" were rewritten:
  - ja: "今に更新" → "更新：{when}", and the same pattern for "設定" and "通知済み".
  - hi: "अपडेट: {when}"; the verb gender had also disagreed between messages.
  - All other languages read correctly for all three kinds of value.

Every language: the safety-critical strings were reviewed against English: recovery phrase, unreadable request and blind signing, scams, look-alike addresses (address poisoning), unlimited approval ("Can take all of it"), suspicious tokens and wrong-network loss. Apart from the fixes listed above, none were weakened. Brand, product and device names were verbatim everywhere except zh-Hans "Ethereum". That includes Clip Wallet, Secure Trade, WalletConnect, Ledger, Ledger Live, Keystone and its “Connect Software Wallet” menu label, Face ID, Touch ID, MetaMask, Phantom, network names and asset symbols. The glossary comment in each language's `index.ts` (UI and mobile) is updated wherever a rule was added.

## Not covered by this pass

- **Mainnet checklist:** no translated strings exist for it, because mainnet is a build flag (`mainnet: false`), so there was nothing to review.
- **Decoded-request warnings in English:** the warnings attached to a decoded request (`Warning.message` from the background and chain modules) are still English in every locale. These include unlimited-approval, domain-mismatch and danger-level scam warnings, and the approval screens render them as-is. They are the strongest safety copy in the product. Localizing them belongs to the background i18n work (branch `r1/bg-i18n`), and that work should reuse these QA checks.
- **Tab labels on small phones:** some are still long, e.g. de "Einstellungen" and "Sammlerstücke", ja "コレクティブル" and "アクティビティ". The new shrink-to-fit keeps them on one line, but check them by eye on a 320–375 pt device.

## Needs a native speaker

Grouped by language. "UI" means the extension catalog, "mobile" the `m.*` catalog.

**All languages**
- Treat Apple's and Google's sign-in button texts as fixed by their brand guidelines: "Mit Apple anmelden", "Appleでサインイン", "Apple로 로그인" and so on. Don't change them for style.

**de**
- "Bringt Erträge" / "Keine Erträge" chips: is there a shorter pair, e.g. "Mit Ertrag" / "Ohne Ertrag"?
- "Ausgelöst jetzt" (from `{when}` = "jetzt") is stiff.
- `security.reason.unusedToken`: "es" or "ihn" for the token?
- `home.asset.bridgedCopy`: "nicht das originale {symbol}" or "nicht das Original-{symbol}"?
- Confirm Apple's German UI says "Apple Account".
- `trade.mode.direct` "Sie ist gerade da": natural?

**fr**
- "Rapporte" / "Ne rapporte pas" on the liquidity chip.
- "Paramètres" vs iOS "Réglages".
- "Mis à jour maintenant" for `{when}` = now.
- Masculine "prévenu" in `social.notify.alert.fired`.
- "sosies" alone in `security.source.local`.
- "Itinéraire" for a swap route.
- "Suivant" for the browser's forward button.
- No-break space after "n°".

**es**
- "Sin confianza" for Cardano's "No confidence" vote.
- "Restaurar con una copia de llave de acceso".
- Masculine "Actualizado" for a list.
- "Saltó ahora".
- `m.trade.share.direct`: "Acéptala en unos 3 minutos"?

**pt-BR**

- "backup por chave de acesso" is heavy.
- Feminine agreement assumed for `{device}` ("na {device}", "nela").
- Generic masculine in "ser avisado" and "você mesmo".
